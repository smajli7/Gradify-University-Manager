## Spezifikationen

- **Format**: PNG (transparent)
- **Größe**: 64x64px oder 128x128px (wird auf 28px skaliert)
- **Farben**: Weiß/Grau (werden durch CSS eingefärbt bei Hover/Active)



Die Icons werden bei Hover und Active-State automatisch aufgehellt und mit Glow versehen.
