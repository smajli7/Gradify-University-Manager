# Berechnungslogik

## 1. Allgemeine Regeln

### Notenskala

Es gilt die deutsche Hochschulnotenskala mit den Werten 1,0 / 1,3 / 1,7 / 2,0 / 2,3 / 2,7 / 3,0 / 3,3 / 3,7 / 4,0 / 5,0. Eine Prüfung gilt als bestanden bei einer Note ≤ 4,0.

### Rundung

Die Gesamtnote wird auf eine Dezimalstelle kaufmännisch gerundet (0–4 abrunden, 5–9 aufrunden). Beispiel: 2,45 → 2,5; 2,44 → 2,4.

### Wiederholungsregeln

| Regel | Bioverfahrenstechnik (BA) | Forschung Soziale Arbeit (MA) |
|-------|---------------------------|-------------------------------|
| Maximale Wiederholungen | 2 (+ 1 auf Antrag) | 2 (+ 1 auf Antrag) |
| Abschlussarbeit | 1 Wiederholung | 1 Wiederholung |

## 2. Bioverfahrenstechnik (Bachelor)

**Rechtsgrundlage:** § 11 Bildung der Gesamtnote (PO 2023)

### Berechnungsformel

$$
\text{Gesamtnote} = \frac{\sum_{i} (\text{Note}_i \times \text{Gewichtung}_i)}{\sum_{i} \text{Gewichtung}_i}
$$

Es werden ausschließlich Module berücksichtigt, deren Bewertungsart „NOTE" ist und deren Gewichtung > 0 beträgt.

## 3. Forschung in der Sozialen Arbeit (Master)

**Rechtsgrundlage:** § 9 Bildung der Gesamtnote (PO 2022)

### Berechnungsformel

$$
\text{Gesamtnote} = \frac{2 \times \text{Note}_{\text{Thesis}} + 1 \times \text{Modulmittel}}{3}
$$

Wobei das Modulmittel das arithmetische Mittel der benoteten Module (ohne Thesis) ist:

$$
\text{Modulmittel} = \frac{\text{Note}_1 + \text{Note}_2 + \text{Note}_3 + \text{Note}_4 + \text{Note}_5 + \text{Note}_7 + \text{Note}_8}{7}
$$

### Beispielberechnung

**Schritt 1 – Modulmittel:**

$$
\text{Modulmittel} = \frac{1,7 + 2,0 + 2,3 + 1,3 + 1,7 + 2,0 + 1,7}{7} = \frac{12,7}{7} = 1,814...
$$

**Schritt 2 – Gesamtnote:**

$$
\text{Gesamtnote} = \frac{2 \times 1,3 + 1 \times 1,814}{3} = \frac{2,6 + 1,814}{3} = \frac{4,414}{3} = 1,471... \approx 1,5
$$

## 5. Validierungsregeln

Die folgenden Regeln gelten bei der automatischen Validierung von Noteneingaben und bei der Gesamtnotenberechnung.

### Bei Notenerfassung

1. Der Notenwert muss im Bereich 1,0 bis 5,0 liegen.
2. Es sind nur die definierten Notenstufen zulässig (1,0 / 1,3 / 1,7 / ... / 4,0 / 5,0).
3. „Bestanden/nicht bestanden" ist nur für Module mit der Bewertungsart BESTANDEN_NICHT_BESTANDEN zulässig.
4. Der Prüfungsversuch darf 3 (bzw. 4 bei genehmigtem Antrag) nicht überschreiten.

### Bei Gesamtnotenberechnung

1. Es werden nur bestandene Module (Note ≤ 4,0) berücksichtigt.
2. Module mit Gewichtung 0 werden ausgeschlossen.
3. Module mit Bewertungsart BESTANDEN_NICHT_BESTANDEN werden ausgeschlossen.
4. Die Rundung erfolgt kaufmännisch auf eine Dezimalstelle.
